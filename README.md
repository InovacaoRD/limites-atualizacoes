# limites-atualizacoes

Instaladores e arquivo de versão do **Limites** (monitor dos limites de uso do Claude, GPT, GLM e Higgsfield). **Não há código-fonte aqui.**

O app consulta o arquivo `latest.json` da última release para se atualizar sozinho e confere a assinatura de cada pacote antes de instalar. Este repositório existe só para que o app consiga baixar as atualizações sem guardar nenhum acesso.

- Mac: `Limites_<versão>_universal.app.tar.gz` (Apple Silicon e Intel)
- Windows: `Limites_<versão>_x64-setup.exe`
